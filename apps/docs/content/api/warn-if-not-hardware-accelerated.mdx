---
title: warnIfNotHardwareAccelerated
description: Log a warning when the GPU adapter is a software fallback.
---

Checks `adapter.info.isFallbackAdapter` and logs a console warning. Common on Android emulators where rendering may be slow or missing features.

## Usage

[`useDevice`](/docs/getting-started/react-api#usedevice) and [`GPUDeviceProvider`](/api/gpu-device-provider) already call it for you. Call it yourself when you request the adapter directly:

```tsx twoslash
import { warnIfNotHardwareAccelerated } from "react-native-webgpu";
// ---cut---
const adapter = await navigator.gpu.requestAdapter();
if (adapter) {
  warnIfNotHardwareAccelerated(adapter);
  const device = await adapter.requestDevice();
}
```

This does not block rendering; it only logs. Test camera, native textures, and performance-critical paths on **physical devices**.
