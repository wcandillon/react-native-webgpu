---
title: GPUDeviceProvider
description: Context provider that requests a device and gates children until ready.
---

`GPUDeviceProvider` requests a `GPUDevice` once and shares it through React context, rendering children only when `device` is non-null. Wrap your scene root so every child can read the shared device with [`useMainDevice`](#usemaindevice) instead of requesting its own.

## Props

```tsx twoslash
import type { ReactNode } from "react";
// ---cut---
interface DeviceProviderProps {
  children?: ReactNode;
  adapterOptions?: GPURequestAdapterOptions;
  deviceDescriptor?: GPUDeviceDescriptor;
}
```

## Usage

```tsx twoslash
import { useEffect } from "react";
import { PixelRatio } from "react-native";
import {
  Canvas,
  GPUDeviceProvider,
  useCanvasRef,
  useMainDevice,
} from "react-native-webgpu";

function Scene() {
  const ref = useCanvasRef();
  // Never null here: the provider renders its children once the device is ready
  const { device } = useMainDevice();

  useEffect(() => {
    const context = ref.current!.getContext("webgpu")!;
    const canvas = context.canvas as HTMLCanvasElement;
    const format = navigator.gpu.getPreferredCanvasFormat();
    canvas.width = canvas.clientWidth * PixelRatio.get();
    canvas.height = canvas.clientHeight * PixelRatio.get();
    context.configure({ device: device!, format });
    // ... render and present
  }, [device, ref]);

  return <Canvas ref={ref} style={{ flex: 1 }} />;
}

export function App() {
  return (
    <GPUDeviceProvider deviceDescriptor={{ requiredFeatures: ["shader-f16"] }}>
      <Scene />
    </GPUDeviceProvider>
  );
}
```

Request features through `deviceDescriptor`: you cannot add features to an existing device later. Native buffer import needs none; it is enabled by default.

While the device is loading, the provider renders nothing. To show a loading state, render it next to the provider, and hide it once your scene has mounted.

## useMainDevice

`useMainDevice` is the hook that consumes this provider's context. It returns the same `{ adapter, device }` the provider created, so any descendant can share that one device instead of requesting its own. If you are not using a provider, [`useDevice`](/docs/getting-started/react-api#usedevice) requests a device directly instead.

```tsx twoslash
import { useMainDevice } from "react-native-webgpu";
// ---cut---
function DebugOverlay() {
  const { adapter, device } = useMainDevice();
  // Read adapter info / feature list, or pass `device` to Three.js, overlays, etc.
  return null;
}
```

<Callout type="warn" title="Must be inside the provider">
`useMainDevice` throws `No DeviceContext found.` when called outside a `GPUDeviceProvider`. Because the provider renders `null` until the device is ready, any child that calls it only mounts once `device` is non-null.
</Callout>
